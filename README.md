Split Glyph is a tool i made to replace the objectively worse practice of substituting greek, cyrillic, and random unicode symbols for text in order to confuse filtering software. its a stupid practice, it limits ur font choices and it quite frankly looks stupid. Split Glyph converts text characters from a variety of fonts to 2-part spit SVGs, which can then be pasted into your project after the styles have been edited within Split Glyph. Sensative strings like "proxy" or "unblocker" can be obfuscated into SVGs to hide them DOM scraping by filtering software to identify your website as problematic, and each SVG is also split into two parts (with orentation and split percentage customizable) to trick any computer vision.
